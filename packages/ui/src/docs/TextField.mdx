## Anatomy

| Part | Style |
| --- | --- |
| Label | font.label, color.text.muted, space.1 above the input |
| Input | space.2 × space.3 padding, color.text.muted border (color.border is too faint for 3:1 contrast), radius.sm, font.body |
| Focus | border becomes color.primary, 2px outline in color.focus |

## Accessibility

- The label belongs to the input: clicking it focuses the input, and screen
  readers read it.
- An error is announced, and the input is marked invalid.
