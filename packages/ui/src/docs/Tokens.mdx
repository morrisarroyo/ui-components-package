# Design tokens

Every value in the token sheet is defined once, as a CSS custom property on
`:root`, and components reference it by name. Use the custom property in CSS;
the dotted name is the token sheet's name for it.

## Typography

Each role is a size, a line height and a weight
(`--ui-font-<role>-size`, `-line`, `-weight`).

| Token | Size / line height | Weight |
| --- | --- | --- |
| font.body | 14px / 20px | 400 |
| font.label | 12px / 16px | 400 |
| font.button | 14px / 20px | 600 |
| font.heading | 20px / 28px | 600 |
| font.title | 24px / 32px | 600 |
