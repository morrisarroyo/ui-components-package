# Patient lookup

All five components in one screen: a search form in a Card, results in a
Table, the chosen patient in a DescriptionList.

## Try it

Search for:

- `lo`, for results (then click a row);
- `zz`, for none;
- `error`, for a failed request;
- one letter, for a validation error.
