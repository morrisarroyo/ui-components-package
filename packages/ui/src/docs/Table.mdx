# Table

One row per record under a header row. Rows can be clickable, and an empty
table shows a message.

## Clickable rows

Set `onRowClick` to make rows clickable by mouse or keyboard. Rows highlight
in color.surface.subtle on hover and while focused.

<Canvas of={TableStories.ClickableRows} />

## Empty state

With no rows, the table shows `emptyMessage` (default "No results"),
centred in color.text.muted.

<Canvas of={TableStories.Empty} />

## Anatomy

| Part | Style |
| --- | --- |
| Header row | font.label, color.text (color.text.muted fails 4.5:1 contrast here), color.surface.subtle background |
| Body rows | font.body, space.3 × space.4 padding, color.border bottom border |

## Accessibility

- Tab to a clickable row; press Enter or Space to open it. Screen readers
  announce it as a button.
- Screen readers can move through the table by row and column.
