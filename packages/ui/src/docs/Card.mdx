# Card

A bordered container that groups related content on a page. It has an optional
title at the top and an optional slot on the same row for buttons; whatever
you place inside it becomes the body.

## Anatomy

| Part | Style |
| --- | --- |
| Container | color.surface background, color.border border, radius.md, space.6 padding |
| Title | font.heading, at the top |
| Actions | right-aligned on the title row |
| Title row | space.4 gap below it |

## Accessibility

- A titled card is a region named by its title, so screen-reader users can
  jump to it.
- The title is an `h2`; place cards under the page's `h1`.
