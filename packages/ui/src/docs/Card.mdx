## Anatomy

| Part | Style |
| --- | --- |
| Container | color.surface background, color.border border, radius.md, space.6 padding |
| Title row | font.heading title, actions on the right, space.4 gap below |

## Accessibility

- Screen-reader users can jump to a titled card by its title.
- The title is an `h2`, so put cards under the page's `h1`.
