# Contributing

How to add a component for building healthcare screens that works like the
others. Full walkthrough, with code for an example `Badge`:
<a href="https://github.com/morrisarroyo/ui-components-package/blob/main/packages/ui/README.md#contributing-extending-the-library" target="_blank" rel="noreferrer">Contributing in the library README</a>.

## Quick start

From the repository root:

```bash
npm install                                        # once
npm run new-component --workspace ui -- Badge      # PascalCase, and a new name
npm run storybook                                  # http://localhost:6006, reloads on save
```

This creates four files and the export:

| File | What goes in it |
| --- | --- |
| `src/components/Badge.tsx` | The component and its typed props. |
| `src/components/Badge.module.css` | Its styles, from design tokens only. |
| `src/components/Badge.test.tsx` | Its behaviour tests. |
| `src/components/Badge.stories.tsx` | One story per variant and state: the demos. |
| `src/index.ts` | The export. |

## Checklist

1. **Props.** A variant, a size, a label. Never a colour, pixel value,
   `className` or `style`.
2. **Styles.** Only `var(--ui-…)` [design tokens](?path=/docs/foundations-tokens--docs).
   A value several components need becomes a new token in `src/tokens.css`.
3. **States.** Hover, focus, error, loading and disabled belong to the
   component, not the page.
4. **Accessibility.** Labelled inputs, keyboard support, native `disabled`,
   and Web Content Accessibility Guidelines (WCAG) 2.2 AA contrast.
5. **Tests.** Find elements as a user would (role, label, text). One
   behaviour per test; no snapshots.
6. **Stories.** One per state.
7. **Docs page.** Copy `Button.mdx` to `src/docs/Badge.mdx` and add it to the
   sidebar order in `.storybook/preview.ts`. Without a page, the component
   doesn't appear here.
8. **README.** Add a `### Badge` section to the library README listing every
   prop exactly as in the code. A test checks it.

## Check it

```bash
npm run lint                            # lint, from the root
npm run typecheck --workspace ui        # types
npm run test --workspace ui             # behaviour, export, stories, README
npm run build --workspace ui            # the package apps install
npm run build-storybook --workspace ui  # this site
```
