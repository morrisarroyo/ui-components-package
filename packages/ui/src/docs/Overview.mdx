# UI Components Package

React components for building Electronic Health Record (EHR) screens, such
as a clinic's patient list and a patient's record. Screens built from them
look and behave alike, and are accessible by default.

| Component | Use it for |
| --- | --- |
| [Button](?path=/docs/components-button--docs) | Running an action. |
| [TextField](?path=/docs/components-textfield--docs) | One line of text, with a label, hint and error. |
| [Card](?path=/docs/components-card--docs) | Grouping content under an optional title. |
| [Table](?path=/docs/components-table--docs) | Many records as rows, optionally clickable. |
| [DescriptionList](?path=/docs/components-descriptionlist--docs) | One record's details as label/value pairs. |

Colours, spacing and type come from the
[design tokens](?path=/docs/foundations-tokens--docs).

## Usage

Import the stylesheet once, then the components:

```tsx
import 'ui/styles.css';
import { Button, Card, TextField } from 'ui';
```

## Principles

- **Few props.** You pick a variant, size or label, never a colour or pixel value.
- **States built in:** hover, focus, error, loading and disabled.

## Accessibility

The components meet the Web Content Accessibility Guidelines (WCAG) 2.2,
level AA:

- keyboard use and visible focus;
- contrast of 4.5:1 for text, 3:1 for borders and focus indicators;
- labelled inputs;
- screen-reader announcements for errors, loading and missing values.

Three colours differ from the design brief to meet contrast: table header
text, the text input border and the focus ring.
